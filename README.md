# yt-batch-unsub

**YouTube Batch Unsubscribe Manager** (v1.2.0)

A clean, privacy-first Edge/Chrome extension that lets you bulk unsubscribe from YouTube channels with:

- Smart selection (Select Visible / Next 20 / Next 50 + search filter)
- Permanent whitelist (protect channels you want to keep)
- Local history + one-click restore
- Human-like delays
- No data leaves your browser

## Features

- Floating toolbar on `youtube.com/feed/channels`
- Checkboxes on each channel
- Search & filter channels before selecting
- Whitelist protection
- History of recently unsubscribed channels with Resubscribe button
- Clear versioning

## Installation (Edge / Chrome)

1. Clone or download this repository
2. Open `edge://extensions/` (or `chrome://extensions/`)
3. Enable **Developer mode**
4. Click **Load unpacked** and select this folder
5. Go to [https://www.youtube.com/feed/channels](https://www.youtube.com/feed/channels)

## Usage

1. Open the extension popup → add channels to **Whitelist** (one name per line) → Save
2. On the channels page the toolbar appears
3. Use search / Select Visible / Next 20 / Next 50
4. Click **Start Unsubscribe**
5. Later you can restore channels from the popup History section

## Privacy

Everything runs locally. No analytics, no external servers, no account required.
